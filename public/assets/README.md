# Asset icons

Cryptocurrency logos are bundled locally from CoinGecko's asset image feed for identification. Respective trademarks belong to their owners; these logos are not covered by Harbour's MIT license.

- FLUX: https://coin-images.coingecko.com/coins/images/5163/large/Flux_symbol_blue-white.png?1696505679

- XRP: https://coin-images.coingecko.com/coins/images/44/large/xrp-symbol-white-128.png?1696501442

Gold uses a Harbour-created gold-bar pictogram because physical gold has no universal brand logo. Unknown crypto and ETF assets retain the letter placeholder.
